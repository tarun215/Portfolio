# Tharun S — Personal Portfolio Website ⚡

A modern, high-performance, SaaS-themed developer portfolio website engineered with clean semantic HTML5, modern CSS3 (with glassmorphism and animated glow effects), and vanilla JavaScript.

🌐 **Live Demo & Repo**: [github.com/tarun215/Portfolio](https://github.com/tarun215/Portfolio)

---

## 🚀 Key Highlights & Features

- **Hero Command Center**: Dynamic typewriter effects, responsive layout, and direct quick-action links.
- **Moving Marquee Tech Ticker**: Continuous infinite ribbon displaying core technologies.
- **Bento Grid Architecture**: Executive summary, interactive developer config terminal, core competencies, and regional impact.
- **Categorized Skills Matrix**: Interactive category filtering (Languages, Web & Frontend, AI & Data, Databases & Tools, Core CS).
- **Featured Projects**:
  - **VajraYield — Rural Market Intelligence Engine**: Deterministic net realization calculations, Kannada & Tulu Web Speech API integration, 27 Vitest cases.
  - **Parametric AI — Industrial Catalog Data Pipeline**: High-throughput PDF extraction pipeline with visual provenance mapping back to source coordinates.
  - **Veterinary Clinic Management System**: 3NF normalized relational database management system.
- **Achievements & Honors Showcase**: Hackathon awards, national coding challenge ranks, and verified certifications.
- **Education Timeline**: Academic milestones from SMVITM Bantakal (VTU) and MGM PU College.
- **Interactive Modals**: Architecture deep dives and interactive PDF resume viewer with instant one-click download.
- **Theme & Sound Customization**: Multiple neon/cyber accent palettes (Hyper Violet, Neon Cyan, Cyber Emerald, Sunset Amber) and Web Audio API synthesized interaction effects.

## 💻 Local Development

1. Clone this repository:
   ```bash
   git clone https://github.com/tarun215/Portfolio.git
   cd Portfolio
   ```
2. Open `index.html` in your browser or run a local HTTP server:
   ```bash
   python -m http.server 5173
   ```
3. Visit `http://localhost:5173` in your browser.
